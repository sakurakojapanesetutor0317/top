N1 GRAMMAR · HOW IT REALLY COUNTS

〜うちに入はいらない・〜も同然どうぜんだ・もはや

Does Not Count As… · As Good As… / Practically… · Already… / No Longer…

Judge what something really amounts to: it is too little to count, it is practically the same as something else, or the situation has already reached a point of no return.

01 Meaning & Quick Comparison

Compare the meanings before choosing an expression.

005 · 〜うちに入はいらない

お菓子かしなんて食事しょくじのうちに入はいらないだろう。ちゃんと食たべなきゃ。
Snacks do not count as a meal. You need to eat properly.

180 · 〜も同然どうぜんだ

相手あいてチームのエースがけが？じゃあ、今日きょうの試合しあいは勝かったも同然どうぜんだな。
The other team's ace is injured? Then today's game is as good as won.

183 · もはや

このような弱よわい薬くすりは、もはや私わたしには効きかないんです。
A medicine this weak no longer works for me.

〜うちに入はいらない: Does not count as… — it is too little or too minor to be called that.

〜も同然どうぜんだ: As good as… / practically… — not literally, but in reality it is the same.

もはや: Already… / no longer… / now… — the situation has changed and cannot go back (formal).

02 How to Form

〜うちに入はいらない

Noun + の + うちに入はいらない ・ verb た-form + うちに入はいらない

Connection example

三十分さんじゅっぷん歩あるいただけでは、運動うんどうしたうちに入はいらない。
Just walking for thirty minutes does not count as exercise. (た-form)

Connection example

この程度ていどの雨あめは、雨あめのうちに入はいらないよ。
This much rain hardly counts as rain. (noun + の)

〜も同然どうぜんだ

Noun + も同然どうぜんだ / も同然どうぜんの + noun ・ verb た-form + も同然どうぜんだ

Connection example

彼かれとは小ちいさい頃ころから一緒いっしょで、兄弟きょうだいも同然どうぜんだ。
We have been together since childhood, so he is practically my brother. (noun)

Connection example

ここまで来きたら、合格ごうかくしたも同然どうぜんだ。
Now that we have come this far, it is as good as passed. (た-form)

もはや

もはや + negative (〜ない: no longer) ・ もはや + noun + だ / 〜しかない (already, now it is…)

Connection example

もはや手遅ておくれだ。
It is already too late. (もはや + noun + だ)

Connection example

スマホはもはや生活せいかつに欠かかせないものになった。
Smartphones have now become indispensable in daily life.

04 Usage Notes & Nuance

〜うちに入はいらない — too little to count

It plays down something as too small or too minor. It is spoken and often used to encourage or to criticize (that is not real exercise / a real meal).

〜も同然どうぜんだ — practically the same

It says that something is not exactly true but is the same in reality. 勝かったも同然どうぜん means victory is practically certain.

もはや — a point of no return

It is formal and written. With a negative it means “no longer”; with a noun it means “already/now (it has become)”. Compare すでに (already, fact) and もう (everyday).

05 Choose the Right Expression

Choose by meaning and context, not only by English translation.

〜うちに入はいらない

運動うんどうのうちに入はいらない。
Does not count as exercise.

〜も同然どうぜんだ

勝かったも同然どうぜんだ。
As good as won.

〜ようなものだ (N2)

家族かぞくのようなものだ。
It is like (comparison).

もはや

もはや手遅ておくれだ。
Already (no return, formal).

もう (N5)

もう遅おそい。
Already (everyday).
How to choose

も同然どうぜんだ is stronger than ようなものだ: it says the result is effectively the same. もはや is a formal もう that stresses the situation cannot return.

06 Common Mistakes

〜も同然どうぜんだ · Correction

✕ 勝かつも同然どうぜんだ。
✓ 勝かったも同然どうぜんだ。
With verbs, use the た-form.

もはや · Correction

✕ （everyday chat）もはやご飯はん食たべた？
✓ もうご飯はん食たべた？
もはや is formal and stresses a point of no return.

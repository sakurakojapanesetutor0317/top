N2 GRAMMAR · POSSIBILITY & COMPLETING THE PROCESS

〜うる／える・〜ようがない・〜抜ぬく

Can Possibly · There Is No Way To · Do Thoroughly / To the End

Say whether something is possible at all, that there is no way to do something, and that something was done thoroughly or all the way through.

N2Possibility & Completing the Process3 grammar points
Masu-stem

01 Meaning & Quick Comparison

Compare the meanings before choosing an expression.

085 · 〜うる／える／えない

それは誰だれにでも起おこりうる問題もんだいだ。
It is a problem that could happen to anyone.

087 · 〜ようがない

住所じゅうしょが分わからないので、連絡れんらくのしようがない。
I do not know the address, so there is no way to contact them.

094 · 〜抜ぬく

マラソンを最後さいごまで走はしり抜ぬいた。
I ran the marathon all the way to the finish.

〜うる／える／えない: Can possibly… / cannot possibly… — a formal way to say whether something is possible at all.

〜ようがない: There is no way to… — no method is available, even if you want to do it.

〜抜ぬく: Do thoroughly / to the very end — finish something difficult, or do it as fully as possible.

02 How to Form

〜うる／える／えない

Verb ます-stem + うる / える (negative: えない)

Connection example

考かんがえうる方法ほうほうは、すべて試ためした。
I have tried every method I can think of. (考かんがえます → 考かんがえ)

Connection example

そんなことはありえない。
That is impossible. (ある → ありえない)

〜ようがない

Verb ます-stem + ようがない (する-verbs: 〜のしようがない / 〜しようがない)

Connection example

こんなに壊こわれていては、直なおしようがない。
It is so badly broken that there is no way to fix it. (直なおします → 直なおし)

Connection example

道具どうぐがないので、開あけようがない。
There is no tool, so there is no way to open it. (開あけます → 開あけ)

〜抜ぬく

Verb ます-stem + 抜ぬく

Connection example

よく考かんがえ抜ぬいて、結論けつろんを出だした。
I thought it through carefully and reached a conclusion. (考かんがえます → 考かんがえ)

Connection example

彼女かのじょは苦くるしい時代じだいを生いき抜ぬいた。
She survived hard times. (生いきます → 生いき)

03 Everyday Examples

Read the Japanese examples, then check the English meaning.

〜うる／える／えない
彼かれが犯人はんにんだということも、十分じゅうぶんありうる。
It is quite possible that he is the culprit.
〜うる／える／えない
想像そうぞうしえないほどの被害ひがいが出でた。
The damage was beyond imagination.
〜ようがない
証拠しょうこがないので、確たしかめようがない。
There is no evidence, so there is no way to check.
〜ようがない
この気持きもちは、言葉ことばでは説明せつめいのしようがない。
There is no way to explain this feeling in words.
〜抜ぬく
一度いちど決きめたことは、やり抜ぬくつもりだ。
Once I decide to do something, I intend to see it through.
〜抜ぬく
悩なやみ抜ぬいた末すえに、会社かいしゃを辞やめることにした。
After agonizing over it for a long time, I decided to quit my job.

04 Usage Notes & Nuance

〜うる / える — formal possibility

It talks about whether something can happen or be done in principle. The dictionary form can be うる or える (ありうる / ありえる), but the negative is always えない. Do not use it for a person’s skill: for “I can swim,” say 泳およげる.

〜ようがない — no method

Even if someone wants to do something, there is no way to do it. With する-nouns, 〜のしようがない is common (連絡れんらくのしようがない).

〜抜ぬく — all the way through

It shows finishing something hard (走はしり抜ぬく, 生いき抜ぬく) or doing something thoroughly (考かんがえ抜ぬく, 悩なやみ抜ぬく). Compare 〜切きる (N3).

05 Choose the Right Expression

Choose by meaning and context, not only by English translation.

〜うる

起おこりうる問題もんだい
Possible in principle.

可能形かのうけい (N5)

私わたしは泳およげる。
A person’s ability.

〜ようがない

直なおしようがない。
No method exists.

〜抜ぬく

走はしり抜ぬく。
All the way to the end, despite difficulty.

〜切きる (N3)

全部ぜんぶ食たべ切きった。
Completely finished.
How to choose

For ability, use the potential form; for possibility in principle, うる / えない. ようがない focuses on the lack of a method. 抜ぬく stresses effort through difficulty, while 切きる stresses that nothing is left.

06 Common Mistakes

〜えない · Correction

✕ そんなことはありうない。
✓ そんなことはありえない。
The negative is always えない.

〜ようがない · Correction

✕ 住所じゅうしょがないので、連絡れんらくするようがない。
✓ 住所じゅうしょがないので、連絡れんらくのしようがない。
Use the ます-stem: する → し.

〜うる · Correction

✕ 私わたしは100メートル泳およぎうる。
✓ 私わたしは100メートル泳およげる。
For a person’s ability, use the potential form.

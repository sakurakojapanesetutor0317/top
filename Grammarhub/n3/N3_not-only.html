N3 GRAMMAR · NOT ONLY… BUT ALSO…

〜ばかりか・〜ばかりでなく・〜はもちろん

Not only… but also…

Learn when the first item is expected and when the added item is emphatic.

01 Meaning & Quick Comparison

Read the meanings and notice when each expression is appropriate.

042 · 〜ばかりか／〜ばかりでなく

この店みせは安やすいばかりでなく、量りょうも多おおいです。
This restaurant is not only cheap; the portions are generous too.

043 · 〜はもちろん〜も

この図書館としょかんには本ほんはもちろん、DVDもあります。
This library has books, of course, and DVDs too.

〜ばかりか／〜ばかりでなく: Not only A, but also B (often surprising or adding emphasis).

〜はもちろん〜も: A is a given, and B too.

02 How to Form

〜ばかりか／〜ばかりでなく

Plain form / Noun + ばかりか・ばかりでなく + B も

Connection example

この店みせは安やすいばかりでなく、量りょうも多おおいです。
This restaurant is not only cheap; the portions are generous too.

Connection example

彼かれは英語えいごばかりか、中国語ちゅうごくごも話はなせます。
He speaks not only English but also Chinese.

〜はもちろん〜も

Noun A + はもちろん + Noun B + も

Connection example

この図書館としょかんには本ほんはもちろん、DVDもあります。
This library has books, of course, and DVDs too.

Connection example

日本語にほんごはもちろん、韓国語かんこくごも勉強べんきょうしています。
I study Japanese, of course, and Korean too.

04 Usage Notes & Nuance

〜ばかりか／〜ばかりでなく

ばかりか often sounds emphatic or unexpected. For a な-adjective, use な before ばかりか/ばかりでなく.

〜はもちろん〜も

はもちろん presents A as obvious or expected, then adds B. Unlike ばかりか, it does not inherently suggest surprise.

06 Common Mistakes

〜ばかりか／〜ばかりでなく · Correction

✕ 上手じょうずばかりでなく
✓ 上手じょうずなばかりでなく
A な-adjective takes な.

〜ばかりか／〜ばかりでなく · Correction

✕ 安やすいばかりか、量りょうが多おおいもです。
✓ 安やすいばかりか、量りょうも多おおいです。
The added item commonly takes も.

〜はもちろん〜も · Correction

✕ 本ほんもちろん、DVDもあります。
✓ 本ほんはもちろん、DVDもあります。
Include は in the fixed expression.

〜はもちろん〜も · Correction

✕ コーヒーはもちろん、紅茶こうちゃがおいしいです。
✓ コーヒーはもちろん、紅茶こうちゃもおいしいです。
Use も to highlight the additional item.

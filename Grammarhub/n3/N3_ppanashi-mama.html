N3 GRAMMAR · CONTINUING STATES

〜っぱなし・〜まま

Leaving something as it is / Keeping a state

Learn how to describe a continuing state, including the difference between neutral and critical nuances.

01 Meaning & Quick Comparison

Compare the meaning and connection before choosing an expression.

〜っぱなし

Leave… as is / Keep doing…

Describe an action or state that continues without being stopped or corrected.

エアコンをつけっぱなしで出でかけてしまいました。
I accidentally went out leaving the air conditioner on.

〜まま

With… unchanged / Without changing…

Describe a state that stays unchanged while something else happens.

眼鏡めがねをかけたまま顔かおを洗あらおうとしました。
I tried to wash my face with my glasses still on.

02 How to Form

Each expression has its own connection pattern.

〜っぱなし

Leave a state unchanged

電気でんきをつけっぱなしで寝ねました。
I fell asleep leaving the light on.

Keep doing an action

一日中いちにちじゅう立たちっぱなしでした。
I was on my feet all day.

Before a noun

開あけっぱなしの窓まどを閉しめてください。
Please close the window that was left open.

〜まま

Verb た + まま

電気でんきをつけたまま寝ねてしまいました。
I fell asleep with the light still on.

Verb ない + まま

朝あさご飯はんを食たべないまま出でかけました。
I went out without eating breakfast.

Noun + の + まま

靴くつのまま部屋へやに入はいらないでください。
Please do not enter the room with your shoes on.

04 Usage Notes & Nuance

〜っぱなし · Two uses

State left as it is: 開あけっぱなし, つけっぱなし. Continuing activity: 立たちっぱなし, 話はなしっぱなし.

〜っぱなし · Not the same as 〜ている

〜ている describes an ongoing action or state neutrally. 〜っぱなし stresses that it continues without a break or has been left unattended.

〜まま · The unchanged state matters

The preceding expression describes what remains as it was. In 電気でんきをつけたまま寝ねる, the light remains on while someone sleeps.

〜まま · A useful distinction

〜たまま describes a resulting state that remains. 〜ないまま says an expected action was not done before something else happened.

05 Choose the Right Expression

These expressions are related, but they are not interchangeable.

〜っぱなし

Describe an action or state that continues without being stopped or corrected.

電気でんきをつけっぱなしにしました。
I left the light on.

〜まま

Describe a state that stays unchanged while something else happens.

窓まどを開あけたまま寝ねました。
I slept with the window open.

06 Common Mistakes

〜っぱなし · Mistake 1

✕ つけますっぱなしです。
✓ つけっぱなしです。
Use the ます-stem: つけます → つけ.

〜っぱなし · Mistake 2

✕ ドアを開あけるっぱなしです。
✓ ドアを開あけっぱなしです。
Use the ます-stem, not dictionary form.

〜まま · Mistake 1

✕ 電気でんきをつけるまま寝ねました。
✓ 電気でんきをつけたまま寝ねました。
Use the た-form for a resulting state left unchanged.

〜まま · Mistake 2

✕ 朝あさご飯はんを食たべなくまま出でました。
✓ 朝あさご飯はんを食たべないまま出でました。
Use the ない-form, not なく.

Gradual Change vs. Opportunity

01 Meaning & Quick Comparison

Read the meanings and notice when each expression is appropriate.

059 · 〜うちに①（変化へんか）

毎日まいにち話はなすうちに、緊張きんちょうしなくなりました。
As I spoke every day, I gradually stopped feeling nervous.

072 · 〜うちに②（機会きかい）

温あたたかいうちに食たべてください。
Please eat it while it is still warm.

〜うちに①（変化へんか）: A change happens gradually while something continues.

〜うちに②（機会きかい）: While a state still lasts / before it changes.

02 How to Form

〜うちに①（変化へんか）

Verb dictionary / ている / ない + うちに

Connection example

毎日まいにち話はなすうちに、緊張きんちょうしなくなりました。
As I spoke every day, I gradually stopped feeling nervous.

Connection example

日本にほんに住すんでいるうちに、生活せいかつに慣なれました。
While living in Japan, I gradually got used to life there.

〜うちに②（機会きかい）

Verb ている / ない, い-adj, な-adj + な, Noun + の + うちに

Connection example

温あたたかいうちに食たべてください。
Please eat it while it is still warm.

Connection example

若わかいうちに、いろいろな経験けいけんをしたいです。
I want to have different experiences while I am young.

03 Everyday Examples

Read the Japanese, then check the English meaning.

〜うちに①（変化へんか）
何度なんども聞きくうちに、歌詞かしを覚おぼえました。

〜うちに①（変化へんか）
練習れんしゅうするうちに、少すこしずつ上手じょうずになりました。
With practice, I gradually improved.
〜うちに②（機会きかい）
若わかいうちに、いろいろな経験けいけんをしたいです。
I want to have different experiences while I am young.
〜うちに②（機会きかい）
雨あめが降ふらないうちに帰かえりましょう。
Let’s go home before it starts raining.
〜うちに②（機会きかい）
元気げんきなうちに、旅行りょこうしたいです。
I want to travel while I am still healthy.

04 Usage Notes & Nuance

〜うちに①（変化へんか）

This use focuses on an unplanned or gradual change during a continuing activity.

〜うちに②（機会きかい）

This use highlights a limited opportunity before the current situation changes; it is not necessarily about a gradual change.

Do not choose only by English translation. First decide whether you need A change happens gradually while something continues or While a state still lasts / before it changes.

06 Common Mistakes

〜うちに①（変化へんか） · Correction

✕ 練習れんしゅうしてうちに、上手じょうずになりました。
✓ 練習れんしゅうするうちに、上手じょうずになりました。
Use the dictionary form or ている, not the て-form alone.

〜うちに①（変化へんか） · Correction

✕ 聞きくうちに、聞きく予定よていです。
✓ 聞きくうちに、覚おぼえました。
The change meaning needs an actual development.

〜うちに②（機会きかい） · Correction

✕ 元気げんきのうちに、旅行りょこうします。
✓ 元気げんきなうちに、旅行りょこうします。
A な-adjective takes な.

〜うちに②（機会きかい） · Correction

✕ 雨あめが降ふらなくうちに
✓ 雨あめが降ふらないうちに
Use the ない-form.

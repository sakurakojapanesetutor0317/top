01 Meaning & Quick Comparison

Compare the meanings before choosing an expression.

078 · 〜ずにはいられない

その話はなしを聞きいて、笑わらわずにはいられませんでした。
I could not help laughing when I heard that story.

079 · 〜てしょうがない／〜てしかたがない

眠ねむくてしょうがないです。
I am so sleepy I can hardly stand it.

〜ずにはいられない: Cannot help doing something; cannot resist an action.

〜てしょうがない／〜てしかたがない: Feel so strongly that it cannot be helped.

02 How to Form

〜ずにはいられない

Verb ない-form minus ない + ずにはいられない; する → せずにはいられない

Connection example

その話はなしを聞きいて、笑わらわずにはいられませんでした。
I could not help laughing when I heard that story.

Connection example

映画えいがの最後さいごで、泣なかずにはいられませんでした。
I could not help crying at the end of the movie.

〜てしょうがない／〜てしかたがない

Verb て-form / い-adj くて / な-adj で + しょうがない・しかたがない

Connection example

眠ねむくてしょうがないです。
I am so sleepy I can hardly stand it.

Connection example

試験しけんの結果けっかが気きになってしかたがありません。
I cannot stop worrying about the exam results.

04 Usage Notes & Nuance

〜ずにはいられない

Expresses a strong involuntary urge or reaction that leads to an action. する is irregular: せずにはいられない.

〜てしょうがない／〜てしかたがない

Usually describes an uncontrollably strong feeling or state. しょうがない is more conversational; しかたがない is somewhat more neutral.

06 Common Mistakes

〜ずにはいられない · Correction

✕ 笑わらわないずにはいられません。
✓ 笑わらわずにはいられません。
Remove ない and add ず: 笑わず.

〜ずにはいられない · Correction

✕ 確認かくにんしずにはいられません。
✓ 確認かくにんせずにはいられません。
する changes to せず.

〜ずにはいられない · Correction

✕ 泣なくずにはいられません。
✓ 泣なかずにはいられません。
Use the ない-stem 泣か.

〜てしょうがない／〜てしかたがない · Correction

✕ 眠ねむいでしょうがない。
✓ 眠ねむくてしょうがない。
An い-adjective uses くて.

〜てしょうがない／〜てしかたがない · Correction

✕ 心配しんぱいてしかたがない。
✓ 心配しんぱいでしかたがない。
A な-adjective / noun-like feeling uses で.

〜てしょうがない／〜てしかたがない · Correction

✕ 旅行りょこうが楽たのしみてしょうがない。
✓ 旅行りょこうが楽たのしみでしょうがない。
Use で after 楽しみ.

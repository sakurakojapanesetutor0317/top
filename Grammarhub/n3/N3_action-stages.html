Action Stages & Freshness

01 Meaning & Quick Comparison

Compare the meanings before choosing an expression.

066 · 〜たて

焼やきたてのパンはいい香かおりがします。
Freshly baked bread smells wonderful.

068 · 〜始はじめる

先月せんげつから日本語にほんごを習ならい始はじめました。
I started learning Japanese last month.

069 · 〜終おわる

メールを書かき終おわってから、出でかけます。
I will go out after I finish writing the email.

〜たて: Freshly or newly done; the result is still fresh.

〜始はじめる: Start doing an action.

〜終おわる: Finish doing an action.

02 How to Form

〜たて

Selected verb ます-stems + たて / たての + noun

Connection example

焼やきたてのパンはいい香かおりがします。
Freshly baked bread smells wonderful.

Connection example

入いれたてのコーヒーを飲のみました。
I drank freshly brewed coffee.

〜始はじめる

Verb ます-stem + 始める

Connection example

先月せんげつから日本語にほんごを習ならい始はじめました。
I started learning Japanese last month.

Connection example

外そとで雨あめが降ふり始はじめました。
It started raining outside.

〜終おわる

Verb ます-stem + 終わる

Connection example

メールを書かき終おわってから、出でかけます。
I will go out after I finish writing the email.

Connection example

本ほんを読よみ終おわりました。
I finished reading the book.

04 Usage Notes & Nuance

〜たて

Used with a limited set of verbs to emphasize freshness right after completion. Do not attach it mechanically to every verb.

〜始はじめる

〜始める marks the start of an activity. 〜出す often highlights a sudden, unexpected start; both can occur with some verbs.

〜終おわる

〜終わる indicates the action has finished. 〜切る stresses completion all the way through; 〜たて describes freshness immediately afterward.

05 Choose the Right Expression

Choose by meaning and context, not only by English translation.

〜たて

06 Common Mistakes

〜たて · Correction

✕ 焼やくたてのパン
✓ 焼やきたてのパン
Use the ます-stem 焼き.

〜たて · Correction

✕ 炊たきたてパン
✓ 炊たきたてのご飯はん
Use たての before a noun; 炊きたて naturally describes rice.

〜たて · Correction

✕ 読よみたての本ほん = “a half-read book”
✓ 読よみかけの本ほん
〜かけ, not 〜たて, describes an unfinished action.

〜始はじめる · Correction

✕ 日本語にほんごを習ならう始はじめました。
✓ 日本語にほんごを習ならい始はじめました。
Use the ます-stem 習い.

〜始はじめる · Correction

✕ 雨あめが降ふって始はじめました。
✓ 雨あめが降ふり始はじめました。
Use the ます-stem 降り.

〜始はじめる · Correction

✕ 仕事しごとを始はじめる始はじめました。
✓ 仕事しごとを始はじめました。
Avoid unnecessarily doubling 始める.

〜終おわる · Correction

✕ 本ほんを読よむ終おわりました。
✓ 本ほんを読よみ終おわりました。
Use the ます-stem 読み.

〜終おわる · Correction

✕ メールを書かいて終おわってから出でかけます。
✓ メールを書かき終おわってから出でかけます。
Use the ます-stem 書き.

〜終おわる · Correction

✕ 宿題しゅくだいをやり終おわるでした。
✓ 宿題しゅくだいをやり終おわりました。
Conjugate 終わる to 終わりました.

〜ことはない・〜べきだ・〜ことだ（助言じょげん）

No need to… / Should…

Compare reassurance, strong judgments, and practical advice: 〜ことはない・〜べきだ・〜ことだ.

N3Advice & Necessity3 grammar points
Dictionary FormNai-form

01 Meaning & Quick Comparison

Compare the meaning and connection before choosing an expression.

〜ことはない

There is no need to… · You don’t have to…

Reassure someone or say an action is unnecessary. Practice the dictionary-form connection and distinguish it from prohibition.

一度いちど失敗しっぱいしただけで、諦あきらめることはありません。
There is no need to give up after failing just once.

〜べきだ

Should… · Ought to…

Express a strong judgment about the right thing to do, including what should not be done and what should have been done.

約束やくそくは守まもるべきです。
You should keep your promises.

〜ことだ（助言じょげん）

上達じょうたつしたければ、毎日まいにち少すこしずつ練習れんしゅうすることです。
If you want to improve, the thing to do is practice a little every day.

〜ことだ（助言じょげん） — The thing to do is… / you should… (general advice).

02 How to Form

Each expression has its own connection pattern.

〜ことはない

Dictionary form

謝あやまることはない。
There is no need to apologize.

Polite

急いそぐことはありません。
There is no need to hurry.

Reassurance

怖こわがることはないよ。
There is no need to be afraid.

〜べきだ

Affirmative

早はやく寝ねるべきです。
You should go to bed early.

Negative judgment

人ひとにうそをつくべきではありません。
You should not lie to people.

Past regret

もっと早はやく連絡れんらくするべきでした。
I should have contacted you earlier.

〜ことだ（助言じょげん）

Verb dictionary / ない form + ことだ

Form

上達じょうたつしたければ、毎日まいにち少すこしずつ練習れんしゅうすることです。
If you want to improve, the thing to do is practice a little every day.

Form

疲つかれているなら、無理むりしないことです。
If you are tired, you should not push yourself.

04 Usage Notes & Nuance

〜ことだ（助言じょげん）

ことだ gives general advice about the best course of action. It is different from ことはない (“no need”) and べきだ (“ought to”).

05 Choose the Right Expression

These expressions are related, but they are not interchangeable.

〜ことはない

Reassure someone or say an action is unnecessary. Practice the dictionary-form connection and distinguish it from prohibition.

無理むりすることはないよ。
There is no need to push yourself.

〜べきだ

Express a strong judgment about the right thing to do, including what should not be done and what should have been done.

約束やくそくは守まもるべきです。
You should keep promises.

〜ことだ（助言じょげん）

疲つかれているなら、無理むりしないことです。
The thing to do is… / you should… (general advice)

06 Common Mistakes

〜ことはない · Dictionary form, not ます-form

✕ 心配しんぱいしますことはない
✓ 心配しんぱいすることはない
Use the dictionary form.

〜ことはない · Dictionary form, not ない-form

✕ 急いそがないことはない
✓ 急いそぐことはない
The “no need to” pattern uses the dictionary form.

〜べきだ · Use the dictionary form

✕ 守まもりますべきだ
✓ 守まもるべきだ
Dictionary form + べきだ.

〜べきだ · Should not = べきではない

✕ 行いかないべきだ
✓ 行いくべきではない
Use べきではない for a negative judgment.

〜ことだ（助言じょげん） · Correction

✕ 毎日まいにち練習れんしゅうしますことです。
✓ 毎日まいにち練習れんしゅうすることです。
Use the dictionary form.

〜ことだ（助言じょげん） · Correction

✕ 無理むりしませんことです。
✓ 無理むりしないことです。
Use the plain negative ない-form.

N4 GRAMMAR · RESULTING STATE

〜てある

Something has been done (and remains that way)

Describe the present result of someone’s intentional action, without focusing on who did it.

N4 · Lesson 30Resulting stateTransitive verb て-form + ある

01 What Does 〜てある Mean?

Use 〜てある to describe a state that exists because someone deliberately did something. The action is already finished; we are talking about its result now.

Transitive verb て-form + ある / あります

Someone did it intentionally

窓まどを開あけました。
Someone opened the window. (action)

The result remains

窓まどが開あけてあります。
The window has been left open. (result)
The key idea

The speaker sees or describes the resulting state. The person who performed the action is usually not important.

02 How to Make It — Start with the て-Form

Use the て-form of a transitive verb, followed by あります (polite) or ある (plain).

書かきます → 書かいてあります
has been written
置おきます → 置おいてあります
has been placed
開あけます → 開あけてあります
has been opened and left open
貼はります → 貼はってあります
has been put up / posted
Why transitive verbs?

〜てある normally describes a state left by someone’s intentional action on an object: 開あける (open something), 置おく (put something), 書かく (write something). By contrast, intransitive change-of-state verbs + 〜ている often describe the state after a change, whether it happened naturally or someone caused it.

03 Particles — Pay Attention to が

With this common result-state pattern, the object of the original action is usually marked by が, not を. A place where something has been put can be marked by に.

Action — OBJECT を

先生せんせいが黒板こくばんに答こたえを書かきました。
The teacher wrote the answer on the board.

Result — OBJECT が

黒板こくばんに答こたえが書かいてあります。
The answer is written on the board.
机つくえの上うえに本ほんが置おいてあります。
A book has been placed on the desk.
壁かべにポスターが貼はってあります。
A poster has been put up on the wall.
Remember the difference

を commonly marks the object when describing the action. が commonly marks the item whose resulting state is being described. This is a useful beginner pattern, not an absolute ban on を in every 〜てある construction.

04 Everyday Situations — Things Already Prepared

You often see 〜てある when checking a room, a schedule, or preparations that someone has already made.

会議室かいぎしつにいすが並ならべてあります。
Chairs have been arranged in the meeting room.
冷蔵庫れいぞうこにジュースが入いれてあります。
Juice has been put in the refrigerator.
旅行りょこうの予定よていがノートに書かいてあります。
The travel plans are written in the notebook.
部屋へやの電気でんきがつけてあります。
The lights have been left on in the room.
Is it always “prepared”?

No. Intentional action is the important idea. The result may be useful preparation, but it can also simply be a state someone deliberately created.

05 〜てある vs. 〜ている — Two Kinds of Resulting States

〜ている does not always mean “is doing.” With an action verb, it can describe an action in progress. With an intransitive verb that expresses a change of state, it often describes the state remaining after the change. The change has already happened.

Ongoing action — 〜ている

先生せんせいが窓まどを開あけています。
The teacher is opening the window. (An action in progress.)

Resulting state — intransitive + 〜ている

窓まどが開あいています。
The window is open. (It opened, and it is now in that state.)

Result of an intentional action — transitive + 〜てある

窓まどが開あけてあります。
The window has been left open. (Someone deliberately opened it.)

Another resulting state — intransitive + 〜ている

財布さいふが落おちています。
There is a wallet on the ground. (It fell and is now lying there — not “is falling.”)
Compare the verb pairs

開あく → 開あいている (intransitive: the window is open) versus 開あける → 開あけてある (transitive: someone left it open). Similarly, つく → ついている (the light is on) versus つける → つけてある (someone deliberately left the light on).

The key is what the verb describes and what the speaker wants to emphasize — an ongoing action, a resulting state, or the result of someone’s deliberate action.

このカフェはもう開あいています。
This café is already open. (The change has happened.)
このカフェはまだ開あいていません。
This café is not open yet. (The change has not happened.)

06 〜てある vs. 〜ておく — Result or Preparation?

These expressions are closely related, but the focus changes.

〜ておく — do something in advance

明日あしたのために資料しりょうを机つくえに置おいておきます。
I’ll put the materials on the desk for tomorrow.

〜てある — the prepared result is there

資料しりょうが机つくえに置おいてあります。
The materials have been placed on the desk.
Quick test

Are you describing what someone will do / did in preparation? → 〜ておく. Are you describing the state left by that action? → 〜てある.

07 Polite, Plain, Past, and Negative Forms

Only ある changes. The first verb stays in its て-form.

FormExampleMeaning
Polite present書かいてありますis written (and remains there)
Plain present書かいてあるis written
Polite past書かいてありましたwas written / had been written
Plain past書かいてあったwas written
Negative書かいてありませんhas not been written
Natural negative expressions

When you simply mean “it is not written,” 書かいていません or 書かいていない may sound more natural in many contexts. 〜てありません is possible but is not the default choice in every situation.

08 Common Mistakes

① Using an intransitive verb with 〜てある

✕ 窓まどが開あいてあります。
✓ 窓まどが開あけてあります。 — Someone has left the window open.
✓ 窓まどが開あいています。 — The window is open.

② Mixing up を and が in the basic pattern

Action: 資料しりょうを机つくえに置おきました。
Result: 資料しりょうが机つくえに置おいてあります。

③ Confusing a completed action with a resulting state

予約よやくしました = I made a reservation.
予約よやくしてあります = A reservation has been made (and is in place).

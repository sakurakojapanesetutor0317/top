自動詞じどうし・他動詞たどうし

Intransitive and Transitive Verbs · It Happens / Someone Does It

Learn the difference between verbs that describe what happens (ドアが閉しまる) and verbs that describe what someone does (ドアを閉しめる). Practice common verb pairs, particles, and resulting states with 〜ています.

N4 · Minna L29Verb Pairs〜が 自動詞じどうし / 〜を 他動詞たどうし
Standalone

01 What Are 自動詞じどうし and 他動詞たどうし?

Many Japanese verbs come in pairs. One verb says what happens to something; the other says what someone does to something.

自動詞じどうし — intransitive: it happens

ドアが閉しまりました。
The door closed. (We only say what happened to the door.)

他動詞たどうし — transitive: someone does it

私わたしはドアを閉しめました。
I closed the door. (A person acts on the door.)
The same event, two viewpoints

Both sentences can describe the same scene. With a 自動詞じどうし, the focus is on the thing and the change. With a 他動詞たどうし, the focus is on the person who does the action.

02 The Key: が or を

An intransitive verb usually takes が for the thing that changes. A transitive verb takes を for the object, and the person doing the action is often the topic or marked with が.

Thing + が + 自動詞じどうし　電気でんきがつきます。
Person + は + thing + を + 他動詞たどうし　私わたしは電気でんきをつけます。

自動詞じどうし + が

授業じゅぎょうが始はじまります。
The class begins.

他動詞たどうし + を

先生せんせいが授業じゅぎょうを始はじめます。
The teacher begins the class.

自動詞じどうし + が

人ひとが集あつまりました。
People gathered.

他動詞たどうし + を

切手きってを集あつめています。
I collect stamps.
Change the verb, not only the particle

✕ 窓まどを閉しまります → ✓ 窓まどを閉しめます / 窓まどが閉しまります. The particle and the verb must match.

入はいる / 入いれる and 出でる / 出だす use the same kanji with different readings. 消きえる / 消けす change both the reading (き / け) and the ending.

04 Patterns That Help You Remember

Some verb endings appear again and again. They are hints, not rules — always check new pairs in a dictionary.

〜aる (自じ) → 〜eる (他た)

始はじまる → 始はじめる
閉しまる → 閉しめる
決きまる → 決きめる
A very common pattern: the intransitive verb ends in 〜aru.

〜れる (自じ) → 〜す (他た)

壊こわれる → 壊こわす
汚よごれる → 汚よごす
The intransitive verb ends in 〜reru, the transitive verb in 〜su.

〜る (自じ) → 〜す (他た)

直なおる → 直なおす
戻もどる → 戻もどす
Many transitive verbs end in 〜su.

〜u (自じ) → 〜eる (他た)

開あく → 開あける
つく → つける
並ならぶ → 並ならべる
Here the transitive verb is the one ending in 〜eru.

〜iる・〜eる (自じ) → 〜す (他た)

起おきる → 起おこす
落おちる → 落おとす
消きえる → 消けす
The transitive verb ends in 〜su.

〜eる (自じ) → 〜u (他た)

割われる → 割わる
切きれる → 切きる
Here the intransitive verb is the one ending in 〜eru.
A useful shortcut

If one verb of the pair ends in す, that verb is almost always the 他動詞たどうし.

05 Describing a State — 自動詞じどうし + 〜ています

An intransitive verb + 〜ています describes the state after a change: the change happened, and the result is still there now (Minna no Nihongo Lesson 29).

電気でんきがついています。
The light is on.
窓まどが開あいています。
The window is open.
財布さいふが落おちています。
There is a wallet lying on the ground. (It fell and is lying there.)
この時計とけいは止とまっています。
This clock has stopped.
いすの足あしが壊こわれています。
The leg of the chair is broken.
コンビニの前まえに車くるまが止とまっています。
A car is parked in front of the convenience store.
Not “is doing”

窓まどが開あいています does not mean “the window is opening.” It means “the window is open.” Compare 先生せんせいが窓まどを開あけています — “The teacher is opening the window” (an action in progress).

06 自動詞じどうし + 〜ています vs. 他動詞たどうし + 〜てあります

Both describe a state that you can see now. The difference is whether you think about the person who did it (Lesson 30).

自動詞じどうし + 〜ています — just the state

窓まどが開あいています。
The window is open. (We just describe it.)

他動詞たどうし + 〜てあります — someone did it on purpose

窓まどが開あけてあります。
The window has been opened (by someone, for a reason).
部屋へやの電気でんきがついています。誰だれかいるのかな。
The light in the room is on. Is someone there?
会議かいぎの資料しりょうはもう机つくえの上うえに並ならべてあります。
The meeting documents have already been laid out on the desk.
Particles

Both patterns usually use が: 窓まどが開あけてあります. For 〜てある, see the 〜てある page.

07 Which Verb Sounds Natural?

Japanese often describes events with an intransitive verb, even when a person was involved. Choosing the right verb changes the feeling of the sentence.

Something broke — no one is blamed

あ、コップが割われた。
Oh, the glass broke.

Admitting that you did it

すみません、コップを割わってしまいました。
I am sorry, I broke the glass.

Announcements

ドアが閉しまります。ご注意ちゅういください。
The doors are closing. Please be careful.

Reporting a problem

部屋へやのエアコンがつきません。
The air conditioner in my room won’t turn on.

Asking someone to act

すみません、窓まどを閉しめてください。
Excuse me, please close the window.

Plans that are settled

旅行りょこうの日ひが決きまりました。
The date of the trip has been decided.
Requests use the transitive verb

You ask a person to do something, so use the 他動詞たどうし: 電気でんきをつけてください / 窓まどを開あけてください. ✕ 電気でんきがついてください.

08 Common Mistakes

Particle and verb do not match

✕ 電気でんきをつきます
✓ 電気でんきをつけます / 電気でんきがつきます
つく is intransitive (が); つける is transitive (を).

Using 〜ています for a state with a transitive verb

✕ 窓まどが開あけています
✓ 窓まどが開あいています
For a state, use the intransitive verb + 〜ています.

Mixing up the readings

✕ 電気でんきを消きえます
✓ 電気でんきを消けします
消きえる (自じ) / 消けす (他た).

A request with an intransitive verb

✕ ドアが閉しまってください
✓ ドアを閉しめてください
Ask a person to act: use the transitive verb.

11. 会議かいぎの時間じかんが（決きまりました・決きめました）。

Show answers

2. つけます — を + transitive verb.

3. 始はじまります — が + intransitive verb.

4. 落おとしました — を + transitive verb 落おとす.

5. 開あいています — intransitive + 〜ています = a state.

6. 消きえる

7. 壊こわす

8. 集あつまる

9. つけて — a request uses the transitive verb in the て-form.

10. 割われた — the intransitive verb describes what happened.

11. 決きまりました — が + intransitive verb.

12. べて — 〜てある uses the transitive verb: 並ならべてあります.
